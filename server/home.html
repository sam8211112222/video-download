VDD helper is running

Videos are saved to ~/Downloads/VDD Videos. Keep this helper running while you browse.

Safari: install the bookmarklet

Show the Favorites Bar (⇧⌘B), then drag both buttons onto it:

⬇ VDD Video  🖼 VDD Image

⬇ VDD Video downloads the video on screen. 🖼 VDD Image downloads the photo on screen, or the cover of the video on screen.

  1. Turn on Safari → Settings → Advanced → “Show features for web developers”.
  2. Then Develop → Developer Settings… → enable “Allow JavaScript from Smart Search Field”.
  3. On Instagram / Threads, scroll so the post is on screen, then click a button in the Favorites Bar.

Chrome: load the extension

  1. Open chrome://extensions and turn on Developer mode.
  2. Click “Load unpacked” and choose the VDD/extension folder.
  3. Hover a video for Video / Cover buttons, or a photo for an Image button (keys: ⌥⇧D video, ⌥⇧I photo/cover).
